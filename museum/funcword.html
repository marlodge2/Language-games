Function words in English

Linguists usually draw a distinction between content words, those words whose meaning is best described in a dictionary and which belong in open sets so that new ones can freely be added to the language, and function words, words with little inherent meaning but with important roles in the grammar of a language. Typically the content words are nouns, verbs, adjectives and some adverbs, while function words are pronouns, conjunctions, prepositions, auxiliary verbs, and some adverbs.

Some of these function words are homonyms of content words, so that only the context can tell you which meaning is intended. Among the adverbs these include BACK, JUST and STILL. Among the auxiliary verbs are CAN, DOES, MAY, MIGHT and MUST. Among the prepositions/conjunctions are DOWN, ROUND and TILL, and among the determiners is MINE. There will be more of these overlaps if you use software which standardises input by stripping punctuation, in which cases items like CAN'T, HE'LL, I'LL, SHE'D and SHE'LL will turn into CANT, HELL, ILL, SHED and SHELL.
