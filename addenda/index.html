ADDENDA

ADDENDA (English) is a new game (Summer 2026) based on rebuilding texts. You see three different texts and one word which you have to add to the right text, one where it makes sense.

The texts are chosen at random from eight which are loaded when the game starts. You can always select QUIT and PLAY AGAIN to get a different selection of texts.

All the texts are quite short, less than sixty words, and we are building up a range so that there is plenty of variety of styles and subjects. The texts are stored in a simple .txt file, so it should be easy to change them or add new ones if you follow the same layout.
